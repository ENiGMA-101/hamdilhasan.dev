# Hamdil Hasan — Personal Portfolio

Static React + TypeScript portfolio for Hamdil Hasan — developer, builder, CSE undergraduate, and photographer.

## Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Vercel-ready static build

## Included

- Responsive portfolio
- About, Work, Focus, Photography, Writing and Contact sections
- All portfolio photography bundled locally
- GitHub, LinkedIn and email links
- Reduced-motion accessibility support
- Production-ready Vite configuration

## Local development

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
npm run preview
```
