Why I Started Building My Own Website

Why I wanted a personal space for writing, experiments, reviews and everything that doesn't belong in a portfolio.

Why I Started Building My Own Website

A portfolio is useful, but it only tells part of the story.

It shows projects, skills and achievements. It doesn't really show the small experiments, strange bugs, useful tools, personal discoveries or lessons that happen between those polished results.

So I wanted another place.

What I want to write about

This site will be a mixture of:

  • technical notes
  • programming experiments
  • robotics projects
  • AI and ML findings
  • software and app reviews
  • interesting tools and websites
  • university experiences
  • life updates and personal thoughts

Not every post will be deeply technical. Some will simply be something I found useful and want to remember.

Why Pelican?

I wanted the site itself to be a learning project.

Pelican gives me a Python-based static-site workflow while still letting me work directly with HTML, CSS, Jinja2 and Markdown.

That means the website can stay simple while I learn from the system behind it.

The goal

I don't want this to be a website that looks finished and then never changes.

I want it to become a record of learning and building.

Let's see where it goes.
